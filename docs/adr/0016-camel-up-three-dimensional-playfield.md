# ADR-0016: 骆驼大赛立体沙盘

Status: accepted

## Context

用户明确否定了首版平面赛道的视觉效果，要求更立体、不局限于简单 2D；同时要求沿用卡坦岛的竖屏布局与适配方式，并自托管更有辨识度的字体。

## Decision

- 仅 `camel-up` 采用按需加载的 Three.js WebGL 2 渲染器。React、TypeScript、Tailwind v4、shadcn 和 Radix 的组件/交互栈保持不变。此项是 ADR-0003 SVG 棋盘约定的游戏专属例外，卡坦岛继续 SVG，传画猜词继续 Canvas 2D。
- 骆驼、沙盘、赛道、金字塔、绿洲和光照以仓库自有程序化几何制作。没有商业原画、商用模型或规则书资产。
- 浏览器只渲染协议投影。几何坐标、相机与射线拾取不参与规则；仅服务器投影的格号可被拾取为操作目标。
- 手机保留紧凑玩家栏、可用高度内的赛场与底部行动区。旋转、缩放和复位只影响镜头。键盘、文本、规则、暗投和所有关键操作仍由 DOM/Radix 提供；通过格号按钮也能放牌。
- 像素比上限 1.8，场景静止时不持续绘制；只在交互、移动与尺寸变化时绘制。减少动态偏好会立即更新位置，不播放旅行动画。重连初始状态直接定位。
- WebGL 不可用或上下文丢失时回退到 SVG 兼容棋盘；规则与操作完整保留。释放场景时清理帧、监听器、纹理、几何和 GPU 资源。
- 当前标题采用得意黑 Smiley Sans，正文采用已有 Noto Sans SC Variable。用户在首轮反馈后要求替换站酷快乐体/霞鹜文楷的手写风格，并将骆驼改为共用轮廓的一体式木质棋子。字体与 OFL 许可随仓库交付，不使用运行时字体 CDN。只有骆驼大赛使用新标题字体。

## Validation

覆盖真实 Chromium WebGL 渲染、手机四个主要竖屏画布/浏览器区域、iPhone 14 兼容、三人对局与重连、旋转缩放复位、上下文丢失回退与无横向溢出。Chromium 模拟不是物理 iPhone 或 iOS Safari 验收。
