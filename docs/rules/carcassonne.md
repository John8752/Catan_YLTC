# 卡卡颂基础版

范围为 `carcassonne`，2–5 人，72 块基础板块（含固定起始板块 D）、每人 7 名可用随从。采用第三版基础计分与农夫规则，不包含河流、修道院长、大随从或其他扩展。允许并列胜利。房间、账号、座位凭证与其他游戏共用，规则与运行状态独立。

## 权威与回合

- 核心接收显式种子，用公共确定性洗牌工具生成 71 张待抽牌。仅服务端保存牌堆顺序；投影只给当前公开板块和剩余数量。
- 起始板块在 (0,0)。抽牌后所有玩家可见当前板块。若所有空位、四种旋转均无法放置，自动弃掉并继续抽；没有可抽牌则终局。
- 按座位依次行动。一个回合的板块位置、旋转和可选随从组成一个原子命令。客户端只预览，完成回合后服务器验证并提交；预览接口从服务器获得合法随从选项，不广播未提交预览。
- 新板块必须边相邻，不能覆盖已有板块，所有相邻边的道路、城市或草地必须一致。旋转为顺时针 0–3 次。交叉路口的各道路在路口结束，不自动互通。
- 随从只能从库存取一名，放在本回合的新板块上；整个连接区域中存在任何随从（含自己）时不能再放。可不放。区域以后合并可以出现多人或同玩家多个随从。
- 命令绑定 matchId 和回合号；非行动者、旧回合、旧对局、无效目标均拒绝。请求 ID 去重；响应丢失后用相同 ID 重试不重复落子。重新开局有全新 matchId。

## 区域与计分

- 城市、道路按板块内部的显式分区连接。田地使用每边两个半边端口，跨边反向连接，不能跨越道路、城墙或地图空洞。不会通过画面像素推导规则。
- 道路没有开放端时完成，每块不同板块 1 分。封闭环路也完成。
- 城市没有开放边时完成，每块不同板块 2 分，每个盾徽加 2 分。一个板块上同城多个区域只计板块一次。
- 修道院自身及周围八格齐全时完成，共 9 分；对角板块参与判断。
- 板块和随从放置后，统一结算当回合所有新完成的区域，包括其他玩家占领的区域。区域内随从最多者获得全分，并列最多者各获得全分。所有参与该区域的随从收回。
- 最后一块可放板块结算后，对所有剩余占领区域执行一次终局计分。未完成道路每板块 1 分；城市每板块、盾徽各 1 分；修道院按自身和现有邻格计分。终局后命令不可再次计分。
- 农夫直到终局才计分且不提前收回。每片田地接触的不同已完成城市各值 3 分，多次接触同城只算一次；不同田地可各自供应同城。多数、并列规则相同。

## 手机交互与信息

竖屏优先，沿用现有字体与自然色桌面。顶部显示座位、分数及剩余随从，中间为可平移、双指缩放的 SVG 地图，底部显示当前板块及分步预览。提供全图、当前预览、最新落子定位。拖动/缩放不提交命令，地图增长不强制重置玩家视角。点击区域可检查整段连接、占领人数、完成状态和田地供应的城市。日志与规则使用 Radix 对话框，不遮挡常驻操作。

验收使用 `tests/e2e/viewport-cases.ts` 的 iPhone 16 / Pro Max 全画布和浏览器区域，补大屏安卓竖屏、桌面以及后期横向/纵向长图。Chromium 模拟不声称真机 Safari 验证。

## 结算与参考

SQLite 只保存 `gameId=carcassonne`、全局唯一 matchId 与版本 1 最终分数/名次摘要，不保存地图、牌堆或运行历史。

规则依据 [出版商基础规则](https://www.hans-im-glueck.de/wp-content/uploads/2024/11/Carcassonne-v3_Rulesheet_EN_web.pdf) 和 [农夫补充规则](https://www.hans-im-glueck.de/wp-content/uploads/2024/11/Carcassonne-v3_Supplement_EN_web.pdf)。24 类基础板块的数量及连接核对 [出版商商店提供的板块表，第16页](https://cundco.de/media/84/a4/ac/1773930056/CC_BigBox_2010_Rule.pdf)。只记录规则事实；所有画面使用原创 3D 几何与兼容 SVG，不复制官方图像、标志或规则书文字。
