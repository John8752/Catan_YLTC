# 德州扑克牌桌设计

用户提供两张竖屏手机扑克界面作为参考，并明确否定方格玩家列表、上下信息面板及装饰性扑克牌。此文件仅约束 texas-holdem，不改变其他游戏。

## 布局

主要场景为朋友在手机浏览器中对局。竖向椭圆绒面牌桌占据屏幕主体，2–9 位玩家沿边缘环坐，自己的头像和底牌固定底部。视图可旋转座位顺序，服务器实际顺时针顺序不可改变。公共牌在中央，底池位于上方，各玩家下注位于桌内且避开公共牌。顶部仅保留房间入口、手数/盲注和配色；底部为本次行动。

翡翠绿参考第一张图的绒面，曜石黑与金色桌边参考第二张图。只使用原创 SVG 几何、单色字母/数字头像与现有玩家颜色，无第三方品牌、头像照片或专有图片。长名称在桌上截断，房间弹窗可完整阅读。

## 牌面

白底、细灰边、3px 圆角、极轻阴影；上方大点数，下方大花色。红桃/方块红色，黑桃/梅花黑色。无倒置角标、无叠加花色。底牌 60×84 CSS px，公共牌按桌面宽度等比调整；accessible name 同时描述花色和点数。牌背不能包含未公开牌值。

## 操作

弃牌为深绿描边，过牌/跟注为浅绿，加注为暖金。加注由 Radix Popover 承接，提供最小、半池、整池快捷值、数字输入、原生滑杆及全下/确认。行动按钮至少 44px。结算详情与最终排名由 Radix Dialog 承接，桌面保持可见，不立即遮住派奖。

## 动效

每手发牌与收池为主要空间叙事，筹码从玩家到下注点，再汇入底池，最后派给赢家。过牌头像确认和文字徽标，弃牌两张牌移向弃牌区，全下多筹码并显示金色徽标，公共牌按街翻开，摊牌时其他争池者翻开底牌。常规飞行 400–440ms、翻牌 400ms、文字反馈 1800ms（减少动态保持完整不透明 1620ms）；发牌最多 18 张，逐张错开 36ms。无循环装饰动效。

动效只消费 protocol 玩家安全 effects，不通过私密手牌差分推断，不在初始加载或重连时重放。支持 prefers-reduced-motion，取消位移/旋转/缩放，保留短透明度确认、可读文字与最终状态。UI 均可通过 DOM 和键盘操作，动画失败时默认内容仍可见。
