# 卡卡颂界面方向

## Direction contract

已确认的受众是熟人同步开房，主设备是大屏手机竖屏。用户明确要求偏 3D 的画风、细致打磨、有意义的动作反馈以及有材质与状态的图标。沿用现有 React / Tailwind / shadcn / Radix、Noto Sans SC 和自然色桌游世界，不更换平台视觉体系。采用 code-led 实现，Three.js 实体几何表达具有厚度的板块和微缩模型，无官方美术或图像素材；SVG 保留为兼容视图。2026-11-25 用户进一步明确要求参考骆驼大赛展示，换成真正的 3D 地图（ADR-0017）。

seed: none (pinned)。依据是本次用户在讨论竖屏地图与底部落子流程后明确要求“ok，综合以上信息，完成游戏的开发”，随后补充“我希望整体画风可以偏3D一些”以及“一定要打磨细致，每个动作要有合理的动效，该强调的地方要强调，每个icon不要干巴巴的”。这些要求与已有 PRODUCT.md 的自然色桌游体系共同固定本次方向；没有运行或虚构抽签、图像定稿和 QUALITY BAR 卡。

### THESIS

手机上的可操作微缩桌面。世界坐标中的地形连续增长，操作控件留在屏幕空间；点选、旋转、派人、确认形成一个可以随时回看的完整回合。

### OWN-WORLD

既有木桌、羊皮纸和松绿的视觉体系延续到新游戏。原创板块采用左上受光、右下投影、浅石城墙、赤陶屋顶和彩色木随从；默认斜俯视展示体积，提供一键俯视保持连接关系。既有游戏不被重新设计。

### STORY

大厅围坐与颜色选择 → 地图点选及旋转预览 → 随从抬起及落位 → 服务器确认的板块落桌与计分 → 下一玩家的座位强调 → 终局全图与排名。

### FIRST VIEWPORT

手机顶部为游戏名、剩余板块、规则/记录/房间入口及同排五座；地图填满中间剩余空间；当前板块与主行动位于底部。地图上直接出现角标与加号候选位置，让操作机制在首屏可见。宽屏沿用流程，操作区移动到右侧。

### FORM

React DOM 承载文字、原生按钮及 Radix 对话框。Three.js 用同一世界相机承载实体板块、棋子和高亮，真实光照和接触阴影塑造体积；投影 DOM 落点和随从按钮跟随相机。触控采用 OrbitControls / Pointer Events，区域选择射线检测真实网格；地形列表保留键盘入口。交互尺寸以 CSS 像素计，地图总览可以缩小，精确选择会回到可操作尺度。动效均有完成点和减少动态路径。已有讨论已选定此结构，没有另行运行 concept-seed 抽签或生成图像定稿。

- 顶部为紧凑座位/分数/随从库存；中央为占据剩余高度的桌面；底部为当前板块、旋转和阶段按钮。桌面宽屏保留同一流程，操作停靠右侧，不把手机界面机械放大。
- 视觉焦点是雕刻边缘、暖色城墙与瓦顶、立体彩色随从。背景为低对比浅苔绿桌垫，外围保留深松绿。光线由左上入射，投影向右下，所有地图内容共享缩放。单指平移、双指缩放平移，独立转向与俯视按钮保留清楚的拼接边界。
- 核心流程为选择落点与旋转 → 选择随从或不放 → 完成回合。服务器投影提供合法选项，提交前均为本地预览。底部放大板块随选择同步，近距离地图小人也能用底部文字按钮选择。
- 正交相机使用世界坐标、缩放和目标点；有限的聚焦与视角过渡有减少动态路径。地图增长不重置视角；提供全图、预览和最新落子定位。拖动超过阈值或出现第二根手指即取消点击，不产生落子。
- 动效语法：候选板块轻抬与吸附，顺时针旋转，随从抬起/落位，已确认新板块单次落桌，得分出现简短结算提示，回合切换通过座位与任务文字同步强调。新连接与重连不重播历史得分。支持 prefers-reduced-motion。
- 细节状态包含选中、按下、焦点、不可用原因、网络处理中、离线保留预览、提交失败相同请求重试、空日志、终局并列名次和房主再来一局。无自动绕行镜头或循环装饰动画。

## Acceptance

手机采用仓库 iPhone 16 / Pro Max 的全画布与浏览器区域、DPR 3；补 412×915 大屏安卓竖屏和桌面。测试正常回合、5人长名称、终局/规则面板、后期双向长图、双指缩放、浏览器栏与安全区变化、网络重试及重连。截图验证真实画面。报告 Chromium 模拟与真机验证的边界。

## 3D implementation evidence

`three/models.ts` 创建原创实体板块、城墙、建筑、树林和木随从；`three/scene.ts` 管理网格批处理、光照阴影、射线选择、相机与销毁。只有正在过渡或画面变化时渲染，DPR 上限 1.6。`Board.tsx` 承载可访问控件与世界投影标记，初始化失败或上下文丢失自动切到 `FlatBoard.tsx`，保留本地落子预览。当前板块的小型说明图及大厅示意保留 SVG。共享字体、布局体系、组件库与其他游戏视觉不变；已有 DESIGN.md 是共同体系基线，渲染器差异以本文件及 ADR-0017 为准。

### 3D finish corrections

总览时小于 52px 的板块投影只显示分组落点标记，点击先放大该片区域；精确尺度才显示单个落点，避免多个 40px 控件遮挡领地。区域计数保留键盘入口。模型在每种随从锚点周围保留净空，房屋与树林放在区域内其他位置，农夫以贴地横卧姿态呈现。正交相机与目标保持 400 世界单位距离，避免缩小后近裁切面切穿桌面。新派遣或新确认的随从从目标表面上方抬起并在 360ms 内落稳，重新连接不补播，减少动态时直接就位。
