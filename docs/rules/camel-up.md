# 骆驼大赛（camel-up）

本仓库独立实现的网页版本，参考 Camel Up 第二版的玩法；所有界面、图形与中文说明独立制作，不收录商业原画、标志或规则书文字。首版沿用平台座位上限，支持 3–6 人。

## 规则约定

- 16 格赛道；五只赛骆驼从 1–3 格出发，两只黑白逆行骆驼从 14–16 格出发。相同格自下而上存储堆叠；上层领先。初始化的顺序与点数由服务器记录输入。
- 每人 3 金币。轮流执行一个行动：领赛段票、移动自己的观众牌、摇骰、暗投总冠军或总末名。六人局还可以与本段未合伙的玩家建立合伙。
- 六颗骰子，每段揭示五颗后结算。领票依次为 5、3、2、2；本段第一名按票面收益、第二名 +1、其余 −1。摇骰票每张 +1；合伙自动复制对方最高非负单票收益（无成本的最优选择）。合计后结算，余额下限 0。
- 移动一只骆驼及其上方的整组。落在其他堆叠上方。灰骰通常按黑白面选逆行骆驼；只有一只驮赛骆驼时选该只；两只逆行骆驼直接相叠时移动上方那只。
- 观众牌不能放第 1 格、非空格或紧邻另一块观众牌。可将已放置牌移到另一合法格。欢呼沿被摇出骆驼朝向多走一格并落顶部；倒彩反向一格并落底部。牌主即时 +1。每段收回所有牌。
- 任意骆驼单位越过终点立即终局（正向 >16 或逆向 <1）；逆向带过线的赛骆驼最落后。先算本段，再按提交顺序结算冠军和末名暗投，正确票依次 +8/+5/+3/+2/+1，错误票 −1，余额不能为负。最多金币的玩家共同获胜。
- 每种颜色的终局卡每人仅一张，冠军和末名共用；进行中仅本人能看到自己的暗投。骰子未来输入及其他人的暗投永不发送给客户端。终局公布已投卡。
- 网页版公开金币余额，方便远程游玩；座位顺序决定首位行动者。无行动时限，断线保留座位。没有自动代打。

## 状态与传输

房间成员转换为规则玩家时，仅允许 `id` 与 `name`；核心初始化与协议玩家投影均使用字段白名单，禁止结构化类型的额外字段通过对象展开混入状态或视图，尤其是座位凭证和账号标识。

新接受的动作生成只含公开数据的 effect；终局暗投 effect 不含颜色。浏览器首次快照或重连只建立基线，后续连续 revision 才播放动作反馈。

规则、状态、排名与合法行动位于 `game-core/camel-up`。随机初始化和每次骰子选择/点数由服务器生成，作为显式输入交给纯引擎。命令绑定 matchId 与 game revision；去重键包含玩家，重试同一命令不再次消费骰子。最终结算保存版本 1 的名次和金币，不保存局中状态。
