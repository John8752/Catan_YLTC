# 多游戏验证记录

日期：2026-09-09。范围：`platform` / `catan` / `draw-guess`。实现及下列本地自动验证已完成；未覆盖的真机与既有可读性问题见下文。

## 必须保持的边界

- 创建房间时固定游戏，不能用设置接口换游戏或发送另一游戏的命令。
- 所有身份共用一个房间目录，最新账号登录先轮换座位凭证，再断开旧连接。
- 每次重开都有新 matchId，旧命令、回调和草稿不能影响新局。
- 传画猜词的草稿、其他画册和未揭晓页面不会出现在别人的 HTTP/WS 视图。
- SQLite 只保存最终活动统计，不保存画笔、词语或草稿。

## 场景矩阵

| 范围 | 场景 |
| --- | --- |
| platform | 两种游戏创建/加入/人数/房主限制；锁定游戏；账号跨游戏接管；重开隔离 |
| catan | 原有规则、交易、私密投影、自动倒计时、AI、账号结算、缓存地图与增量历史；手机布局 |
| draw-guess core | 3/4/5/6 人每画册每人一次；同时提交；状态不可变；非法内容、阶段、玩家和过期任务 |
| draw-guess protocol | 只展示自己的任务与草稿；只展示前一页；揭晓前缀与未知玩家拒绝 |
| draw-guess server | 私密草稿不广播；序号单调；断线超时；幂等提交/揭晓；结算失败重试；新局 ID |
| draw-guess browser | 六个隔离浏览器完成全局、画布刷新恢复、同步逐页揭晓与同房间重开；触屏画布不带动页面滚动 |
| draw-guess mobile | iPhone 16 / 16 Pro Max，portrait full-canvas 与 browser-area，六人及长名称 |

## 已执行的验证

| 命令 | 实际结果 |
| --- | --- |
| `pnpm validate` | 通过；包含 `pnpm check`、`pnpm test`、`pnpm build`。336 项测试：core 70、protocol 48、server 66、web 152 |
| `pnpm test:replay` | 通过；1 项完整合法卡坦对局重放，另 1 项非目标用例跳过 |
| `pnpm test:boundaries` | 通过；4 项依赖、隐私与确定性边界 |
| `pnpm test:platform` | 通过；35 项公共协议、身份/房间和网页入口测试 |
| `pnpm test:draw-guess` | 通过；20 项传画猜词规则、投影、服务端和草稿测试 |
| `pnpm test:e2e --workers=2` | 最终复跑 114 项全部通过，耗时 3.8 分钟；包含全部 45 项 `@primary-phone` 手机用例 |

完整浏览器回归覆盖大厅选择/加入/房主移交、卡坦原有多人行为、六个独立浏览器的完整传画猜词对局、刷新恢复、36 次同步揭晓与同房间再开新局。初次回归发现测试冻结时钟阻止懒加载页面在首次挂载和刷新后渲染；调整为挂载后冻结、刷新前恢复时钟，保留全部提示时序和重连不重播断言，失败用例先单独重跑通过。

跨局边界另外使用确定性延迟请求复现：上一局开局点评不能写入下一局；旧局/旧回合的 AI 意图请求不能消耗当前回合额度；相同交易内容也不能使旧操作自动重试到新局。

## 环境与限制

浏览器引擎为 Playwright Chromium；未运行物理 iPhone 或真实 iOS Safari，模拟截图不能作为 Safari/真机认证。按 Playwright skill 的验证流程补充了截图检查和隔离多浏览器验证。

浏览器测试单独启动 5184/8794 服务，使用内存 SQLite，不读取开发 `.env` 或外部 AI 配置，不复用已运行的 `pnpm dev`。部署环境仍为 plain HTTP，未新增需要 secure context 的 API 或麦克风权限。网页按游戏懒加载；生产构建通过，没有单一超大游戏入口 chunk 警告。

没有部署到线上，也没有运行生产数据库迁移。本次复用已有按 gameId 分区的最终结算结构，没有新增数据库 schema；传画猜词仅写版本 1 的参与统计，不持久化画作、词语或草稿。服务器重启仍丢失运行中房间。

Screenshots and traces go to ignored `output/playwright` / `test-results`, never into Git.
